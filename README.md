# Storm Harbor organization profile

This repository contains the public profile shown on the
[Storm Harbor GitHub organization](https://github.com/Storm-Harbor).

The rendered organization overview lives in [`profile/README.md`](profile/README.md).

[Product website](https://stormharbor.io/) · [Getting Started](https://storm-harbor.github.io/storm-harbor-control-plane/getting-started/) · [Development issues](https://github.com/Storm-Harbor/storm-harbor-control-plane/issues)

This repository also owns the shared [engineering guidance](AGENTS.md),
[contract/delivery/acceptance specifications](specs/), contribution and security
policies. Public branding uses Storm Harbor; technical documentation stays in
English and describes implemented capabilities separately from planned runtime
integrations. The website maintains all configured locale catalogs together.
